# agent-console

Локальный ИИ-агент в терминале. Запускаешь — он сам проверяет окружение, подключается к модели и
работает с твоей машиной: выполняет команды PowerShell, читает и пишет файлы, ищет по коду.
Интерфейс — цветные панели с потоковым выводом, история сохраняется.

## Быстрый старт

```powershell
cd tools\agent-console
.\start-agent.cmd --selftest   # проверка установки
.\start-agent.cmd --init       # мастер настройки (провайдер, модель, ключ)
.\start-agent.cmd              # интерактивный чат
```

Лаунчер сам создаёт виртуальное окружение в `%LOCALAPPDATA%\atoll-agent\venv` и ставит зависимости.

Разовый запуск без чата:

```powershell
.\start-agent.cmd -p "покажи, какие версии dotnet установлены"
```

## Провайдеры

| Провайдер | Что нужно | Модель по умолчанию |
|---|---|---|
| `ollama` | установленный [Ollama](https://ollama.com), без ключей и VPN | `qwen2.5-coder:7b` |
| `anthropic` | `ANTHROPIC_API_KEY` или ключ в конфиге | `claude-sonnet-4-5` |
| `openai` | ключ + base URL (подходит любой OpenAI-совместимый прокси) | `gpt-4.1-mini` |

Для Ollama: `winget install Ollama.Ollama`, затем `ollama pull qwen2.5-coder:7b`.

## Режимы подтверждений

- `ask` — спрашивает перед каждым действием;
- `smart` (по умолчанию) — чтение без спроса, команды и запись файлов с подтверждением;
- `yolo` — полный доступ без вопросов.

## Команды в чате

```
/help                     справка
/mode ask|smart|yolo      режим подтверждений
/model <имя>              сменить модель
/provider ollama|anthropic|openai
/cd <путь>                рабочая папка
/clear                    очистить историю
/status                   состояние сессии
/exit                     выход
!команда                  выполнить локально, минуя модель
```

## Инструменты агента

| Инструмент | Назначение |
|---|---|
| `run_command` | команда в PowerShell / bash, таймаут до 900 с |
| `read_file` | чтение файла с номерами строк |
| `write_file` | создание и перезапись файла |
| `list_dir` | содержимое папки |
| `search_files` | поиск по содержимому (rg, иначе регэксп в Python) |

## Файлы

- конфиг: `%APPDATA%\atoll-agent\config.json`
- сессии: `%APPDATA%\atoll-agent\sessions\<id>.json`
- переменные окружения: `ATOLL_AGENT_PROVIDER`, `ATOLL_AGENT_MODEL`, `ATOLL_AGENT_BASE_URL`, `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`

## Ограничения

- только текст: мышь, окна и скриншоты недоступны;
- агент не работает, когда приложение закрыто;
- `yolo` даёт модели полный доступ к машине — включай осознанно.

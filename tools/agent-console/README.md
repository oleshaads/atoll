# agent-app

Одноклик: чат с агентом Arena из терминала. Приложение само ставит зависимости, само
проверяет и при необходимости устанавливает GitHub CLI, само проводит вход в GitHub,
само создаёт канал связи в репозитории и само пересылает сообщения в обе стороны.

## Запуск

Двойной клик по **`run.cmd`** (или `python app.py`).

Первый запуск попросит один раз войти в GitHub: откроется браузер, введи показанный код.

Если есть готовый токен (PAT с правами `repo` и `workflow`) — можно без браузера:

```powershell
python app.py --token ghp_xxxxxxxx
```

Проверка установки:

```powershell
python app.py --selftest
```

## Что умеет

| Действие | Как |
|---|---|
| написать агенту | просто текст + Enter |
| выполнить локально, без агента | `!команда` |
| скриншот экрана и отправка агенту | `/shot` |
| отправить файл агенту | `/send C:\путь\файл.txt` |
| забрать файл от агента | `/get имя-файла` |
| проверить ответы сейчас | `/sync` |
| состояние канала | `/status` |
| выход | `/exit` |

## Как устроен канал

- Сообщения — файлы `chat/<номер>.json` в ветке `chat` этого репозитория.
- Файлы для обмена — ветка `bridge-out` (туда же складывает вывод фоновый workflow `agent-bridge`).
- Приложение опрашивает канал каждые 4 секунды и печатает новые ответы.

**Ограничение, которое нельзя обойти:** агент читает канал, только когда открыт чат Arena.
Пока чат закрыт, сообщения ждут в репозитории — ответ появится, когда агент их прочитает.
Поэтому приложение — это удобный терминал и очередь, а не автономный ИИ.

## Если нужен полностью автономный агент

`agent_console.py` работает без Arena и без GitHub: подключается к модели по API-ключу
(Anthropic / OpenAI / Ollama) и выполняет задачи сам.

```powershell
.\start-agent.cmd --init    # выбрать провайдера и ключ
.\start-agent.cmd           # чат с моделью
```

## Ограничения

- Управление мышью и окнами недоступно: только консоль, файлы и скриншоты.
- Скриншот снимается на этой машине и уходит в репозиторий — не запускай `/shot` с открытыми секретами на экране.
- Ветки `chat` и `bridge-out` видны всем, у кого есть доступ к репозиторию. Репозиторий публичный — не пиши туда пароли и ключи.
